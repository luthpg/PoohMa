# PoohMa 機能一覧（Feature Catalog）

家族間アカウント管理アプリ「PoohMa」が提供する全機能を、業務カテゴリおよび画面・ユーザー視点から体系的に整理した機能一覧ドキュメントです。
各機能の実装状況（✅ 実装済 / ⏳ 未実装）を明記しています。詳細な仕様や要件番号は [要件定義書 (requirements.md)](./requirements.md) を参照してください。

---

## 1. 認証・ユーザー管理 (Authentication & Identity)

| 機能名 | 概要 | 対象画面 | 対応要件ID | 実装状況 |
| :--- | :--- | :--- | :--- | :---: |
| **Google アカウント認証** | Firebase Authentication（リダイレクト方式）による Google OAuth ログイン・サインアップ。 | ログイン画面 | `FR-AUTH-01` | ✅ 実装済 |
| **長期セッション永続化** | Firebase Auth（IndexedDB + LocalStorage）を本体とした数ヶ月単位のログイン維持。セッションCookie（14日間）の自動ローリング延長。 | 全画面共通 | `FR-AUTH-02`, `FR-AUTH-07` | ✅ 実装済 |
| **ユーザー情報同期 & アカウント引き継ぎ** | 初回・再ログイン時に表示名・メール・アイコンをDB同期。同一メアドの再登録時は過去データ（レコード・家族申請）を自動継承。 | バックエンド | `FR-AUTH-03` | ✅ 実装済 |
| **安全なログアウト** | Firebaseサインアウト、サーバー側リフレッシュトークン即時失効、Cookie削除、ローカル暗号キャッシュ完全破棄。 | メニュー | `FR-AUTH-04` | ✅ 実装済 |
| **マルチアカウント管理** | 1つのGoogleログイン（Firebase UID）に対して、実家用・配偶者用など複数のPoohMaアカウントを作成・独立保持。 | 設定画面, メニュー | `FR-AUTH-08` | ✅ 実装済 |
| **アクティブアカウント即時切替** | メニューからワンクリックでアカウント切替。切替時に前アカウントのMasterKeyを揮発性メモリから即時破棄し、再ロック状態へ安全に遷移。 | メニュー | `FR-AUTH-09` | ✅ 実装済 |
| **プロフィール設定** | アカウントの表示名を変更可能。 | 設定画面 | `FR-AUTH-05`, `FR-SET-01` | ✅ 実装済 |
| **アカウント削除・退会** | 「現在のアカウントのみ削除」または「PoohMa全体からの退会（Firebaseアカウント削除）」を選択可能。誤操作防止の確認文字列入力付き。 | 設定画面 | `FR-AUTH-06`, `FR-AUTH-10`, `FR-SET-03` | ✅ 実装済 |

## 2. 家族グループ管理 (Family Management)

| 機能名 | 概要 | 対象画面 | 対応要件ID | 実装状況 |
| :--- | :--- | :--- | :--- | :---: |
| **家族グループ作成** | 家族名と家族パスコード（10〜72文字、zxcvbnスコア2以上）を設定して新規グループ作成。マスターキーを同時生成。 | 家族管理画面 | `FR-FAM-01` | ✅ 実装済 |
| **家族招待（コード/URL/QR）** | 有効期限（1時間〜30日）付きの招待コード・招待リンク・QRコードを発行。QRコード画像保存および Web Share API による外部共有。 | 家族管理画面 | `FR-FAM-02`, `FR-FAM-11` | ✅ 実装済 |
| **参加申請・承認制フロー** | 招待コード経由での参加申請（pending）。既存家族メンバーによる明示的な承認（approved）または却下（rejected）。申請の本人キャンセル。 | 家族管理画面 | `FR-FAM-03`, `FR-FAM-04` | ✅ 実装済 |
| **メンバー一覧照会** | 現在所属する家族グループのメンバー一覧（表示名、メールアドレス）を表示。 | 家族管理画面 | `FR-FAM-05` | ✅ 実装済 |
| **家族パスコードローテーション** | 家族グループを解散・移行することなく、パスコードのみを変更。展開済みマスターキーの再ラップのみで完結し、O(1) で高速・安全に完了。 | 家族管理画面 | `FR-FAM-10` | ✅ 実装済 |
| **家族グループの移行** | 別の家族グループへ所属を変更。既存レコードの暗号化データを新マスターキーで安全に再ラップする2段階トランザクション（PREPARED → COMPLETED）。 | 家族管理画面 | `FR-FAM-06`, `FR-FAM-07` | ✅ 実装済 |
| **メンバー除名（キック）** | 不正または不要になったメンバーを家族から除名。共有レコードは家族資産として保護し、個人レコードのみ旧暗号鍵退避（Export Vault: 30日間）経由で持ち出しを許可（ファミリー管理者のみ実行可能、最後の管理者の除名は禁止）。 | 家族管理画面 | `FR-FAM-09` | ✅ 実装済 |
| **デフォルト権限・非対称ロール管理** | 家族内に「ファミリー管理者（全操作・全レコード管理）」と「メンバー（共有レコードの既定はヒント閲覧・復号のみ、個人レコードや任命された共有レコードの編集・管理は可能）」のロールを導入。低リテラシー層の誤操作・データ破壊を防止しつつ、個別レコードへの管理者任命や一括管理者設定に対応。 | 家族管理画面, 詳細画面, ダッシュボード | `FR-FAM-12`, `FR-REC-26` | ✅ 実装済 |

## 5. エンドツーエンド暗号化 & セキュリティ (E2EE & Security)

| 機能名 | 概要 | 対象画面 | 対応要件ID | 実装状況 |
| :--- | :--- | :--- | :--- | :---: |
| **Zero-Knowledge E2EE** | パスワードヒントをクライアント（ブラウザ）の Web Crypto API で暗号化。サーバーには暗号文のみを送信し、平文は一切預からない。 | 全暗号処理 | `FR-REC-06`, `FR-CRYPT-02` | ✅ 実装済 |
| **エンベロープ暗号化** | 家族パスコード → マスターキー（AES-GCM 256） → レコード固有 DEK（AES-GCM 256） → ヒント本文の3層鍵階層。 | 暗号コア | `FR-CRYPT-01`, `FR-CRYPT-02` | ✅ 実装済 |
| **PBKDF2 鍵導出 & バージョン管理** | PBKDF2（SHA-256、300,000回反復）。反復回数とスキームバージョンをスキーマ管理し、旧データの互換性を保ちながら将来の強度引き上げに対応。 | 暗号コア | `ADR-002`, `ADR-006` | ✅ 実装済 |
| **揮発性メモリアクセス制御** | 展開されたマスターキーはブラウザの React State/Ref 上でのみ一時保持。ストレージへは一切永続化せず、リロードやアカウント切替で消去。 | 全画面共通 | `FR-CRYPT-05` | ✅ 実装済 |
| **誤入力指数バックオフ & ロックアウト** | パスコード誤入力時、3回目以降に指数バックオフ（1秒〜最大30秒）の遅延を設定し、総当たり攻撃を抑止。 | パスコード解除モーダル | `FR-CRYPT-04` | ✅ 実装済 |
| **無操作自動ロック (Inactivity Lock)** | 一定時間操作がない場合、メモリ上のマスターキーを自動破棄して再ロック状態へ遷移（時間は設定画面で変更可能）。 | 全画面共通 | `FR-CRYPT-03`, `FR-SET-02` | ✅ 実装済 |
| **生体認証ロック解除 (WebAuthn PRF)** | パスコードを端末のセキュア領域で暗号化保持し、指紋/FaceIDのワンタップでパスコード入力を代行・ロック解除。非対応端末へのフォールバック。 | パスコード解除モーダル, 設定画面 | `FR-BIO-01` 〜 `FR-BIO-05` | ✅ 実装済 |
| **印刷用リカバリーキット発行** | パスコード忘却時に備え、復元コードとQRコードを記載したA4印刷用PDFを発行。ローカル保存・印刷・Google Drive直接保存に対応。 | 家族管理画面 | `FR-CRYPT-06`, `FR-CRYPT-08` | ✅ 実装済 |
| **2段階アカウント復元 (Redeem)** | リカバリーコード入力 ＋ 登録メールアドレスへのワンタイム認証コード（Email OTP: 10分有効・試行制限）による厳格な本人確認を経てマスターキーを救出。 | リカバリー画面 | `FR-CRYPT-07` | ✅ 実装済 |
| **クリップボード自動消去** | パスワードヒントをコピーした後、30〜60秒後にOSクリップボードを自動消去する漏洩防止機能。 | レコード詳細画面 | 検討中 | ⏳ 未実装 |
